# VoxVarta AI 📰

An AI-powered personalized news assistant built using Streamlit.

## Features
- AI news summarization
- Personalized news feed
- Ask questions about news
- Voice-enabled news (listen feature)
- Credibility checker
- Sentiment analysis
- Daily highlights

## Tech Stack
- Python
- Streamlit
- HuggingFace Transformers
- GNews API
- TextBlob
